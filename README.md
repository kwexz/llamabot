# Telegram Bot - Генератор ответов в стиле участников

Бот, который анализирует переписку Telegram группы и генерирует ответы в стиле каждого участника.

## Требования

1. Установленная и запущенная Ollama
2. Модель `yandex/YandexGPT-5-Lite-8B-instruct-GGUF:latest` должна быть загружена в Ollama
3. Python 3.7+

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что Ollama запущена и доступна на `http://localhost:11434`

3. Убедитесь, что модель загружена:
```bash
ollama pull yandex/YandexGPT-5-Lite-8B-instruct-GGUF:latest
```

## Использование

Запустите бота:
```bash
python telegram_bot.py
```

### Первый запуск

При первом запуске бот автоматически:
1. Загрузит и проанализирует сообщения из `result.json`
2. Создаст портреты стиля общения для каждого участника через Ollama
3. Сохранит портреты в локальную SQLite базу данных `user_profiles.db`
4. Будет готов отвечать на вопросы

**Примечание:** Создание портретов может занять некоторое время, так как для каждого участника вызывается Ollama.

### Последующие запуски

При следующих запусках бот:
1. Загрузит сохраненные портреты из SQLite базы данных `user_profiles.db`
2. **НЕ будет переобучать модель** - использует сохраненные портреты
3. Сразу будет готов отвечать на вопросы

Модель обучается **один раз** и не переобучается при каждом запуске.

### Принудительное переобучение

Если нужно переобучить модель заново (например, после обновления `result.json`), используйте флаг `--retrain`:

```bash
python telegram_bot.py --retrain
```

Или сокращенный вариант:
```bash
python telegram_bot.py -r
```

## Формат вопросов

Задавайте вопросы в формате:
```
Какая музыка тебе нравится ^Тимур^
Что думаешь о погоде ^Юрий^
Как дела? ^Ilya Samoylov^
```

Где `^Имя^` указывает, в чьем стиле должен отвечать бот.

## Выход

Для выхода введите: `exit`, `quit` или `выход`
